# Bright Bite Kitchen

Build a polished, mobile-first website for a food brand called “Hot, Fast & Healthy Bites.”

The brand helps busy beginners make quick, healthy, satisfying meals without complicated ingredients or techniques. The tone should feel energetic, warm, encouraging, and practical.

DESIGN

- Create a clean, appetizing visual style with warm cream backgrounds, tomato red or chili orange accents, and fresh green details.

- Use bold, readable headings and high-quality food photography.

- Make the layout responsive and easy to navigate on phones.

- Keep the pages fast, accessible, and uncluttered.

PAGES AND CONTENT

1. Home page

   - A strong headline: “Hot, Fast & Healthy—Dinner Made Simple.”

   - A short introduction explaining that the recipes are beginner-friendly and quick to make.

   - Prominent buttons: “Find a Recipe” and “Follow on Pinterest.”

   - Featured recipe cards with image, cooking time, and a clear title.

   - Sections for “Ready in 20 Minutes,” “Healthy Comfort Food,” and “Beginner Favorites.”

   - A simple email signup section for weekly recipe ideas.

2. Recipe collection page

   - Display recipes in attractive cards.

   - Add filters for meal type, preparation time, and dietary preference.

   - Include a search bar.

   - Use realistic sample recipe content and images, clearly presented as examples that can be replaced.

3. Individual recipe page template

   - Show the recipe title, appetizing image, prep time, cook time, servings, and difficulty.

   - Include a short introduction, ingredients, numbered instructions, substitutions, and storage tips.

   - Add a “Print Recipe” button and a clear Pinterest save/share button.

   - Include a note area for nutrition information, without inventing exact nutrition values.

4. About page

   - Introduce the brand as a helpful resource for busy people learning to cook quick, healthy meals.

   - Keep the copy friendly and concise.

FUNCTIONAL DETAILS

- Make navigation, search, filters, recipe cards, email signup, print button, and social links work or provide a clear setup-ready placeholder.

- Add Pinterest buttons that link to a placeholder profile URL that is easy to replace.

- Use semantic headings, accessible color contrast, descriptive image alt text, and visible keyboard focus states.

- Do not use fake testimonials, fake subscriber counts, or unsupported health claims.

- Make recipe content easy to update later.

Build the actual website, not just a static design mockup. Start with the home page and create a cohesive, reusable design system for the other pages.
